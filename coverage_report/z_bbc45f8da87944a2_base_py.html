1"""VectorStore Protocol and shared exceptions. 

2 

3NF4 swappable abstraction: any implementation that satisfies this Protocol can 

4replace QdrantVectorStore via dependency injection. The Protocol is sync — 

5route handlers offload via `anyio.to_thread.run_sync` (DESIGN §6.1). 

6 

7``QdrantUnreachableError`` lives in ``backend.app.api.errors`` as a 

8DomainError subclass (T10a) and is re-exported here. ``CollectionMissingError`` 

9stays a plain internal exception per DESIGN §5 — it never reaches users; 

10the orchestrator turns the A12 "no active article" case into the user-facing 

11``NoActiveArticleError`` upstream.
